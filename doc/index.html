1. Setup and conventions

The distribution is spectral-reconstruction; import it as spectral. From the repository root:

python -m pip install -e '.[applications,notebooks,test]'

HLT approximates a target kernel with a linear combination of correlator basis functions:

C(t) = ∫ ρₚ(ω) φₜ(ω) dω
φₜ(ω) = ωᵖ B(t, ω),   K̂(ω) = Σᵢ qᵢ φᵢ(ω)
reconstructed value = qᵀ C,   statistical variance = qᵀ Cov(C) q

Integrals start at omega_0. This support boundary is distinct from a target's energy cut. Use consistent energy/time units and the same spectral power p for basis, target and model representation; units are not automatically converted.

2. Reconstruction API

Entry pointPurpose
sp.CorrelatorData.from_arraysInput times, means and covariance. select_times() restricts the basis data.
sp.BasisForward kernel, input times, spectral power and lower integration boundary. sp.kernels.exponential() also supports periodic propagation.
hlt.SolverLambda values, identity/covariance regulator and optional linear constraints.
sp.ReconstructorCombines basis, solver and numerical backend; reconstruct() computes coefficients and predictions.
sp.targetsCorrelator, Gaussian, HVP windows (FULL/SD/ID/LD), and smooth/sharp high-energy targets.
sp.numericsnumpy() for binary64 or mpmath(dps=60) for arbitrary precision. Decimal strings preserve input precision.

This small example reconstructs time 4, which is absent from the input basis:

import spectral as sp
from spectral.algorithms import hlt

data = sp.CorrelatorData.from_arrays(
    times=[1, 2, 3], mean=["1.0", "0.6", "0.4"],
    covariance=[[".01", 0, 0], [0, ".008", 0], [0, 0, ".006"]],
)
basis = sp.Basis(
    kernel=sp.kernels.exponential(), times=data.times,
    p=2, omega_0="0.3",
)
solver = hlt.Solver(lambda_=["0", "1e-6", "1e-3"], regulator="identity")
reconstructor = sp.Reconstructor(
    basis=basis, algorithm=solver, numerics=sp.numerics.mpmath(dps=60),
)
prediction = reconstructor.reconstruct(
    data, target=sp.targets.correlator(basis=basis), target_times=[4],
)
result = prediction.at_lambda("1e-6").at_time(4)
print(result.value, result.statistical_error)
print(result.coefficients)
print(result.approximated_kernel(["0.3", "0.5", "1"]))

Arrays introduce named axes, even with one element. Use at_lambda(), at_time() or select() to select a result. A withheld-time prediction is approximate, including at lambda zero.

HLT uses W = (1−λ)A + λR, with 0 ≤ λ < 1. For covariance regularization, set regulator="covariance", covariance_norm=...; statistical errors still use the original covariance.

Constraints

Pass constraints to the solver explicitly. Endpoint matching uses the target value at omega_0; use value="0" for a vanishing endpoint:

solver = hlt.Solver(
    lambda_=["1e-6", "1e-3"],
    constraints=[hlt.constraints.point(energy=basis.omega_0, value="target")],
)

hlt.constraints.area() matches integrated areas when those integrals exist. The library rejects divergent or incompatible constraints.

3. Scans, systematic errors and storage

APIUse
sp.targets.grid(factory, vary=..., **fixed)Cartesian scan over target parameters, such as cut widths.
sp.scan.reconstructScan a mapping of named sp.scan.Ensemble(data, basis, metadata) objects. Targets and algorithms may be mapped by ensemble name. Supports checkpoints and validated resume.
sp.execution.processes(workers=...)Shared worker budget for reconstruction. Put process execution inside a guarded main(); serial execution is the default.
sp.systematics.estimateIntegrate (K̂ − K_reference)ρₚ for a nominal model and optional deformations. Returns signed biases and their maximum absolute value, without correcting the central estimate.
sp.scan.selectStatDominantMinimum filters parameter ranges and statistical dominance, then minimizes statistical and systematic errors in quadrature.
sp.io.save / load / write_csvNative .spectral archives retain results and reports; CSV provides scalar summaries. Replacement requires overwrite=True.
sp.io.jksread_correlator() imports JKS data; to_jks() applies coefficients to retained/source resamples and preserves correlations. Mean and covariance alone are insufficient for this export.

sp.SpectralDensity defines a physical density. Implementations in sp.models include TwoPionModel and TabulatedSpectralDensity; neither takes a power p. Use density.integrate(kernel) for physical integration. sp.systematics.estimate(..., density=density) and sp.systematics.integrand(density=density, kernel=basis.at_time(t)) handle the basis-power conversion. gaussian_deformations(density=...) makes reusable physical density variations. An explicit energies= grid selects finite-grid trapezoid integration; otherwise systematic integration is adaptive.

Run the Glarger application

Run the full workflow with the same Python environment used to install the application dependencies and your easyfit package:

python applications/Glarger_ID_scan/run.py \
  --data-dir /path/to/input_data \
  --output-dir /path/to/results \
  --n-workers 4

The runner checks dependencies, then runs scan, selection and continuum extrapolation in order. Outputs are grouped into scan_output/, plots/ and continuum_output/ beneath the selected output folder. It stops on errors; use --resume to reuse matching scan checkpoints. Individual stages remain available below.

Edit scan_inputs.py: ENSEMBLES defines input ensembles; SCAN defines lambdas, cuts and widths; GLOBAL_HLT selects solver settings; SYSTEMATIC controls model variations. Place 96I.jks, Ca.jks, 48I.jks, 64I.jks and r_ratio_pdg.csv in the application's data/ folder.

python applications/Glarger_ID_scan/run_multi_ensemble_hlt_scan.py --check-inputs
python applications/Glarger_ID_scan/run_multi_ensemble_hlt_scan.py --n-workers 4
python applications/Glarger_ID_scan/select_minimum.py
python -m jupyter lab applications/Glarger_ID_scan/plot_single_hlt_scan_table.ipynb

The scan writes scan_output/; selection writes selected_minimum_total_error_results.csv there and PDFs in plots/. --smoke-test runs a small subset. Selection uses stat ≥ factor × |systematic|, with default factor 0.5; the scan notebook has independently editable selection settings.

The application preserves the legacy finite-grid R-ratio systematic prescription in systematics.py. Unlike the general library envelope, it uses distorted spectra only, excluding the nominal model. The default endpoint value is zero. To match the target at the endpoint, set GLOBAL_HLT = GlobalHLTConfig(endpoint_value="target") in scan_inputs.py. Use None to disable it; rerun the scan after changing constraints.
